Fern Canopy is a lush green Chrome theme built on a single verdant value ladder: a forest-green frame, a slightly lighter green toolbar, and a soft mint New Tab Page that brightens every new tab. Cream ink keeps every tab, bookmark and toolbar icon crisp against the dark chrome, while deep forest text and links keep the pale page easy to read. A single-row shortcut layout and a color-matched Google logo keep the page clean and uncluttered. Solid colors only, no wallpaper — calm, leafy, and easy on the eyes.
